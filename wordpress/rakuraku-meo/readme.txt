=== ラクラクMEO 店舗情報連携 ===
Version: 0.1.0
Requires at least: 6.2
Requires PHP: 8.0
License: GPL-2.0-or-later

店舗の確認済み情報を管理し、明示的に公開を許可した店舗情報ブロックと、MEO管理画面へのJSON照合データを作成します。
Googleの自動更新・順位保証はありません。ページ本文や既存SEOプラグインの設定は変更しません。

1. ZIPをWordPressのプラグイン追加からインストールし有効化。
2. 設定→ラクラクMEOへ店舗名・公開住所・電話・営業時間・予約URLを入力。
3. 公開する場合は店舗の承認を得て公開欄を選択。固定ページへ [rakuraku_meo_profile] を配置。
4. 既存のLocalBusiness構造化データがあるページには重複設置しない。住所非公開の訪問型事業は住所を空欄にする。
5. 照合データをJSONで保存。MEO側で公式サイトURLを登録した店舗を選び、設定→WordPressの店舗情報から取り込む。
6. 取込は未確認資料。GBPの実値・公開ページと照合し、正式情報を別途承認する。

管理画面と店舗ブロックはWordPressの言語に合わせ日英中韓に対応。設定値自体は自動翻訳しません。
公開停止：設定の公開欄を解除。無効化しても保存情報は保持。削除時も設定値を勝手に削除しません。
検証：WordPress 7.1.3 / PHP 8.4.25。個別テーマ・他SEOプラグインとの公開前照合が必要。
